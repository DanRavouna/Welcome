# Critter Roll

An original creature-collector web game. Play it at https://danravouna.github.io/critter-roll/ once GitHub Pages is turned on (Settings → Pages → Deploy from branch `main`, folder `/`).

- `index.html` is the built game. Rebuild it with `python3 src/build2.py`.
- `src/` holds the source and tests. `critter-roll-handoff.md` covers the design and history.
